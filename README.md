## Aturan Main (Wajib Dibaca Sebelum Coding)

Agar tidak terjadi *conflict* saat digabung (*merge*), mohon patuhi 3 aturan simpel ini:

* **NO INLINE CSS!**
  Dilarang keras menulis *style* langsung di HTML (contoh: `style="color: red;"`). Semua *styling* **wajib** ditulis di file `style.css` yang terpisah. Panggil elemen menggunakan `class` atau `id`.
* **Kerja di Kavling Masing-Masing**
  Adit sudah membuatkan batas berupa komentar HTML (contoh: `<!-- HERO SECTION - GALANG -->`). Kalian hanya boleh mengetik kode HTML dan CSS untuk bagian kalian sendiri. Jangan mengubah kode di luar kavling kalian.
* **Gunakan Branch**
  Jangan langsung *push* ke `main`. Buat *branch* baru dengan format: `namafitur-namakamu` (contoh: `hero-adit`). Setelah selesai, buat **Pull Request** agar bisa dicek bareng-bareng.
